System Architecture

            
Planner ➔ Tool ➔ Assistant Workflow

          

        

        
      


      

        

          

            
1. User Query

            
User Prompt

            
Receives natural language instruction from the user.

          

          
          


          

            
2. Planner (LLM)

            
Tool Selection & Parsing

            
Evaluates prompt against tool registry and returns strictly formatted JSON with the selected tool & extracted arguments.

          


          


          

            
3. Tool Execution

            
Deterministic Execution

            
Locally executes safe math AST parser, secure password generator, or system clock.

          


          


          

            
4. Assistant (LLM)

            
Natural Synthesis

            
LLM receives the user prompt, tool name, and raw result to formulate a friendly, conversational final answer.

          

        


        

          
 Production Ready Deployment
